# Student Performance Analysis

Load and preprocess a student dataset (marks, attendance, study hours), analyze performance trends, identify what drives results, and present it all in an interactive dashboard.

## Files

| File | Purpose |
|------|---------|
| `raw_student_data.csv` | Raw data (2,400 exam records) with missing values and bad data entries |
| `cleaned_student_data.csv` | Cleaned data, ready for analysis |
| `student_analysis.py` | Python pipeline: generate, preprocess, analyze, build dashboard |
| `dashboard_template.html` | Template the script fills with data — keep it alongside the script |
| `student_dashboard.html` | The interactive dashboard (open in any browser) |

The dataset is a sample generated for this project: 160 students across 4 sections (10-A to 10-D), 5 subjects, 3 terms. To use your own data, point `RAW_CSV` in the script at your file. It needs these columns: `student_id, class, term, subject, marks, attendance_pct, study_hours`.

## Steps Completed

1. **Load and preprocess.** Out-of-range attendance values (some below 0% or above 100%, from data-entry errors) were treated as invalid and cleared, then missing marks were filled with the subject's average and missing attendance with the class's median.
2. **Subject-wise and overall trends.** Average marks per subject, and the overall average across all three terms (rising trend).
3. **Factors affecting performance.** Correlation between marks and both attendance and study hours, plus average marks broken down by attendance band and study-hours band.
4. **Group comparison.** Average marks by class section.
5. **Charts.** A line chart for the term-wise trend, bar charts for subject, class, and study-habit comparisons, and a pie chart for grade distribution.
6. **Insights.** Written up below, and shown directly on the dashboard.

**Correlations:** attendance vs. marks is 0.49, study hours vs. marks is 0.42 — both moderate-to-strong positive relationships, confirming both are real, related factors rather than noise.

## Insights for Improving Academic Results

1. **Attendance matters:** students attending 90-100% of classes average 79.0 marks, versus 66.7 for those under 70% attendance — a 12.3-point gap. Raising low-attendance students above 80% looks like the single biggest lever available.
2. **Study hours matter too:** students studying 12+ hours a week average 79.8 marks versus 67.1 for under 4 hours — a 12.8-point gap. Structured study-hour targets (8+ hours/week) are worth setting.
3. **Mathematics** is the weakest subject overall (67.6 avg) while **Computer Science** is the strongest (77.3 avg) — Mathematics would benefit from extra practice sessions or revised teaching materials.
4. **10-D** trails the other sections (69.4 avg vs. 76.2 in 10-A). Its weakest spot is Mathematics (63.2 avg) — a targeted intervention there would lift the section's overall average.
5. **The trend is positive:** the average moved from 70.9 in Term 1 to 76.2 in Term 3 (+5.3 points), suggesting current support measures are working and should continue.

These same five points are generated by the script from the actual numbers (not hand-written) and appear on the dashboard itself, so they update if you re-run the analysis on different data.

## How to Run

1. **Check Python.** Run `python --version` (`python3 --version` on Mac/Linux); you need 3.8 or newer.
2. **Install libraries:**
   ```
   pip install pandas numpy
   ```
3. **Keep `student_analysis.py` and `dashboard_template.html` in the same folder** — the script needs the template to build the dashboard.
4. **Run it:**
   ```
   python student_analysis.py
   ```
   On Mac/Linux use `python3 student_analysis.py`.
5. **Read the printed report**, then open the generated `student_dashboard.html` in your browser.

To just view the dashboard without re-running anything, download `student_dashboard.html` and open it directly (or use the published link), the same as with the earlier Sales dashboard.

## Using the Dashboard

- **Filters** (top right): Class, Subject, Term. Every chart and KPI updates together.
- **KPIs:** average marks, average attendance, average study hours, and pass rate for the current filter.
- **Term-wise trend (line):** shows one line per subject when "All" subjects is selected, or a single line when you pick one subject.
- **Subject-wise / class-wise (bar):** always shows every subject or class, regardless of the matching filter, so you can compare while still slicing by the other filters.
- **Grade distribution (pie):** A/B/C/D/F breakdown (90+, 75+, 60+, 40+, below 40) for the current filter.
- **Performance by study habits (bar x2):** average marks grouped into attendance bands and study-hours bands, which is how the two "factor" insights above were found.
- **Insights panel:** the five findings above, generated directly from the data.

## Assumptions and Limitations

- Grading bands (A: 90+, B: 75+, C: 60+, D: 40+, F: below 40) follow a common convention; adjust `grade()` in the script if your school uses different cutoffs.
- Attendance and study hours are recorded per student per term (same value across that student's subjects); marks are per subject.
- Correlation shows association, not proof of cause — other factors (home environment, teaching quality, prior grades) aren't in this dataset.
- The sample dataset is synthetic. Real results will differ once you substitute actual school data.

## Ideas for Improvement

- Add gender or socioeconomic fields, if available and appropriate, for a fuller picture of equity in outcomes
- Track individual students over time to flag those falling behind early in a term rather than only at the end
- Add teacher- or classroom-level identifiers to separate teaching effects from section effects
- Export the filtered view as a PDF report for parent-teacher meetings
